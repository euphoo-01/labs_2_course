# **№ 7 Создание WPF пользовательских ЭУ**

## Задание

1)  Разработайте два *пользовательских* элемента управления.

2)   Добавьте в них несколько **DependencyProperty** с валидацией через
    ValidateValueCallback и коррекцией CoerceValueCallback

3)  Добавьте события на основе **RoutedEvent**. Используйте разные типы
    маршрутизации (Direct, Tunneling, Bubbling). Продемонстрируйте
    разницу между типами маршрутизации.

4)  Продемонстрируйте использование элементов в проекте.

5)  Создайте пользовательскую команду на основе RoutedUICommand.
    Используйте ее в проекте.
